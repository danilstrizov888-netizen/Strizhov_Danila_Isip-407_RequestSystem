Прототип интерфейса системы учёта заявок



\---



Экран 1. Вход (login.png)



Назначение: вход в систему.  



Действия: ввести логин/пароль, войти, восстановить пароль.



\---



Экран 2. Список заявок (tickets.png)



Назначение: просмотр всех доступных заявок.  



Действия: поиск, фильтр по статусу/категории, открыть заявку, создать новую.



\---



Экран 3. Создание заявки (create\_ticket.png)



Назначение: создание новой заявки.  



Действия: заполнить тему, описание, выбрать категорию, создать, отменить.



\---



Экран 4. Карточка заявки (ticket\_card.png)



Назначение: просмотр полной информации о заявке.  



Действия: взять в работу, отметить выполненной, закрыть, удалить (с подтверждением), комментировать.



\---



Экран 5. Редактирование заявки (edit\_ticket.png)



Назначение: изменение данных заявки.  



Действия: изменить поля, сохранить, отменить.

Ошибки и подтверждения



\- Ошибка входа: «Неверный логин или пароль».



\- Пустой список: «Заявок пока нет. Создайте первую».



\- Удаление: «Удалить заявку? Это действие нельзя отменить».
